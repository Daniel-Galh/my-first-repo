# GitHub glossary

- **Repository (repo):** a project folder on GitHub that remembers every change.
- **Commit:** one saved change, with a note saying what changed.
- **Commit message:** the short note attached to a commit.
- **README:** the "read me first" file that explains the repo.
- **Markdown (.md):** a simple text format; `#` makes a heading, `-` makes a bullet.
- **Diff:** the view showing what changed; green = added, red = removed.
- **Fork:** your own copy of someone else's repo.
- **Claude Code:** a tool where Claude edits and commits files in a repo for you.
- **Branch:** a safe side copy of the repo where you try changes without touching main.
- **Pull request (PR):** a request to review a branch's changes before merging them into main.
